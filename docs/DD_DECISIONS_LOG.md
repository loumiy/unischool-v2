# DD decisions changed without a chat

From Phase 21E onward the dev plan runs without stopping between phases, by
the author's instruction. CLAUDE.md's rule — _anything that would change an
existing DD decision is raised in chat first_ — is replaced for that run by
this: the phase makes the call, writes the amendment into the DD in the same
PR, flags it at the top of the PR body, and records it here, so every
existing decision that moved can be reviewed in one place.

Additive DD edits (a new section, a decision where the DD was silent) are not
listed; they are flagged in their PR bodies as before.
